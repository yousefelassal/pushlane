## What Pushlane handles

Pushlane maps your user ID to active installations and routes notifications through APNs, FCM, or Web Push. Your app still requests notification permission and completes its platform setup. Your backend authenticates the user before it issues an installation registration token.

A provider accepting a message does not prove that the device displayed it. Pushlane reports provider acceptance explicitly. Read [delivery states](/reference/delivery/) before you build alerts around them.
